Reduces avoidable subscription-agent overhead exposed by a basic benchmark run
that took 53 seconds, seven calls and about 154k cumulative tokens for one level.

- Pane and benchmark CLI turns expose 13 common native tools and two discovery/
  invocation tools, instead of all 213 schemas and the full handshake index.
  All enabled specialised tools remain reachable through paginated schema discovery.
  Ordinary external MCP clients keep their full native catalogue.
- Driving instructions use supplied document/selection/level IDs and query only
  missing facts. Simple operations no longer require a blanket project survey
  or a model-report call. Complex operations still require targeted verification.
- Codex model discovery is shared for five minutes across modeller/judge tasks.
  Refresh bypasses the cache; CLI, config and account-file metadata changes
  invalidate it. Subscription authentication remains checked for every CLI run.
- Progress identifies seed checks, copy opening, evidence, model/context setup,
  judging and reset. The Revit column reports native dispatcher execution;
  JSONL also records catalog, context, model/tools, MCP waits and Revit queue time.
  Parallel wait sums can overlap; they are not subtracted from total modelling time.
- Fresh-copy startup uses a lightweight eligibility probe before opening the copy,
  avoiding a redundant full snapshot of the seed.
- Objective evidence now includes level names/elevations and grid curves, so
  correct simple tasks are not penalised for missing proof of their names/lengths.
- Free-form batch/gateway argument schemas preserve arbitrary keys. Disabled
  groups and code opt-in apply to discovery, invocation and batching.

159 pure tests plus isolated WPF, HTTP/stdio MCP and subscription CLI checks
cover discovery/pagination, gateway arguments, gating/cancellation, cache refresh
and account/config invalidation. A manual GPT-6.1 Sol subscription smoke also
executed one gateway call with arbitrary UTF-8 arguments against the production
MCP transport and an isolated fake dispatcher; no Revit document was touched.
Builds target Revit 2025, 2026 and 2027.
These checks do not establish an after-update timing inside live Revit; model
inference and service latency still vary. Compare runs using the same model,
effort, judge and saved seed, and record the execution profile/version.

Includes the document-identity/chat-input fixes from v3.7.3 and all advanced
family/reinforcement/standards features. Close Revit before installing.
