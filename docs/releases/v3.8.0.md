# Claude Revit v3.8.0

Complex modelling now has parameter generators, better benchmark evidence and independent work in open document tabs. This release registers 222 built-in tools.

- `generate_floor_stack`: native floors/levels from per-storey contours, holes, elevations, offsets, scale and rotation. Validates the full table before editing and reports any requested alignment displacement.
- `generate_facade_grid`: native, unhosted module families on a parameter grid. `generate_spire`: native family Revolution in RFA or explicitly identified DirectShape in RVT, with parameters saved for replacement. All three default to rollback preview; commit with `preview:false`.
- `validate_csharp` compiles without executing. Script references isolate assemblies which embed their own Newtonsoft.Json. Results, warnings and errors stay in one JSON value.
- `export_image` uses native Revit view export, checks PNG pixels, rejects black images and returns image content to the agent.
- A task journal records all dispatched native calls, queue/execution/wall timings, exact added/modified/deleted IDs and category counts. The pane has **Copy log**. Native BIM versus DirectShape and source/assumption annotations are available through `set_model_provenance` / `audit_model_provenance`.
- Each open document has its own chat, draft, attachments, agent/model choices and running task. Queued native calls remain bound to their document. UI operations require the intended tab to be active; closing a document cancels its task.
- Codex and Claude Code MCP modes can call native subagents for independent planning/checking. Codex caps spawned concurrency at three; Claude receives the same three-worker guidance and two tool-free planning/checking roles. Parent agents perform Revit changes in dependency order on its single API thread. Simple operations do not need delegation. API chat has no new delegation tool.
- Rebar types can be created in an empty architectural template. Steel-only seeds without a valid concrete column host/type skip R1/R3 without points. Native connection types and connected structural member IDs are accessible through two new tools; generic connections explicitly report their lack of fabrication geometry.
- The benchmark checks actual mesh/solid surfaces, rebar layouts/hosts, joint members and provenance. Task-specific hints reduce unnecessary discovery. Quality/speed scoring, subscription defaults and all 29 tasks remain. Codex accounting distinguishes per-turn counters from cumulative fallback; delegated usage is marked parent-only.

Use the same seed, judge, effort and task subset when comparing results. These changes address missing tools and missing evidence; they do not guarantee a higher score or a particular modelling time. Subagents can consume more subscription allowance.

Validation includes pure-logic tests, isolated WPF pane checks, real local HTTP/stdio transport with a dispatcher double, fake subscription CLI processes and builds against supported Revit APIs. These checks do not replace running the native geometry/reinforcement tasks in Revit on representative RVT/RFA seeds.
