# v3.9.2 — built-in ModPlus integration

Adds four built-in tools: `get_modplus_tools`, `get_modplus_algorithm`,
`modplus_sum_parameters` and `run_modplus_command`. The 12 October 2026 snapshot
maps 84 available Revit 2027 modules and 215 declared commands, with paged discovery,
live ribbon matching and local-source inspection. The source catalog is not a full
headless port: only parameter summation has a fixed read-only public-service adapter;
other installed commands use Revit's interactive UI.

Execution checks Revit 2027, the active bound project, service context and the exact
sum-module SHA-256. Selection is restored after reading, including failure/cancellation.
Interactive posting is refused in unattended benchmarks and returns `completed=false`.
The unchanged prepared extension is superseded without deleting its file; edited
custom tools still follow the code-execution switch. Decompiled vendor sources and
DLLs stay local and are not included in release packages.

350 unit tests and 41 isolated adapter checks passed; builds target Revit 2025/2026/2027.
Native execution with installed ModPlus remains unverified. See
[setup, examples and exact limits](https://github.com/debug23win/ClaudeRevit/blob/main/docs/modplus.md).
