# v3.9.4 — Claude API fixes, current models, lighter ModPlus integration

## Claude API

- **Fable 5.1 no longer fails on the second tool round.** For accounts created from 31 August 2026, the API rejects an edited conversation history for models with preserved thinking. Every tool round removed the document context from the previous request, which counted as an edit and returned a 400. For Fable 5.1, Opus 5.5, Sonnet 5.5 and Haiku 5.5 the history is now append-only:
  - the document and selection context stays in its user message;
  - the system prompt is kept as first sent for the whole conversation;
  - what can still change (a newly loaded tool group, a model switch) is covered by `block_binding: drop_block`, so the API drops the reasoning it can no longer trust instead of rejecting the request;
  - a request still rejected for its thinking blocks is resent once without them.
- **New models:**
  - Opus 5.5, Sonnet 5.5 and Haiku 5.5 are in the chat and benchmark model lists;
  - Opus 5.5 and Sonnet 5.5 use the server-side refusal fallback;
  - conversation summaries run on Haiku 5.5, with Haiku 4.5 as the fallback.

  The default model and Auto mode are unchanged.
- **Refusals and cut-off replies.**
  - A declined reply is no longer shown as an answer. Its partial text and tool calls are discarded, and the chat names the classifier category.
  - A reply cut off by the output limit or the context window says so.
- **Cost display follows current prices:**
  - Opus 5 at $5/$25 (it was shown at $10/$50);
  - Sonnet 5 at $2/$10;
  - cache reads at $0.25 per million tokens for Fable 5.1 and $0.20 for Opus 5.5;
  - Haiku 5.5 priced per request by prompt size.
- **Benchmark judge:** a 16K output budget, so thinking cannot crowd out the verdict, and an explicit error on refusal.

## Claude Code subscription mode

- **npm installs on Windows.**
  - The extensionless `claude` shell script is no longer picked over `claude.cmd`.
  - Arguments passed through cmd.exe are kept on one line, so `--allowedTools` and `--resume` are no longer cut off by the multi-line driving rules.
- **Fable 5** now runs Fable 5 instead of the CLI's default model.
- **Token counts** include cache tokens.

## ModPlus

- **The router is deferred.** `run_modplus_headless` is no longer sent with every request. It loads with the ModPlus group, on a ModPlus keyword or through `find_tools`.
- **Aliases are opt-in.** The 85 per-module aliases register only with `CLAUDEREVIT_MODPLUS_ALIASES=1`, so Revit 2027 has 293 tools by default (378 with aliases). API chat never loads them; the router covers every module.
- **Faster startup.** The binding snapshot is parsed on first use instead of at Revit startup, which saves about 0.2 s and 15–28 MB.
- **Smaller DLL.** The snapshots are embedded gzip-compressed: the add-in DLL is 6.9 MB instead of 16.2 MB for Revit 2027, and about 6.0 MB for 2025/2026.
- **Active-tab check.** It also applies to edited `ModPlusTools.cs` overrides.
