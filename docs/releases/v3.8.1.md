# v3.8.1 — document attachments and request supplements

- Attach several documents/images through the paperclip, drag and drop, or paste
  copied files. All extensions are accepted, with explicit parser notices for
  unsupported or unreadable content.
- Read PDF text by page, DOCX text, XLSX sheets/cached values, PPTX slide/notes text,
  ODF, plain text and ZIP entries through `read_attachment`. Images reach the
  agent as native vision content. Proprietary binary files supply their stored
  path for a suitable native tool; scanned PDF OCR is not included.
- Add text and documents while the model works using **Дополнить**. Updates reach
  API model iterations or MCP tool results; late updates continue in the same
  conversation. **Stop** is separate and unsent drafts stay intact.
- Keep staged files, pending attachments and updates scoped to their project
  conversation. Sent filenames persist in history and copied logs.
- Parse on worker threads, page extracted content and keep the prompt to a short
  manifest. Limits: 20 files, 100 MiB each, 200 MiB per message.

[Usage, format support and limits](../chat-attachments.md).

Validation: 180 unit tests, isolated WPF pane/benchmark controls, scoped HTTP MCP
integration checks and CLI parsing checks. Release builds target Revit 2025/2026
(.NET 8) and Revit 2027 (.NET 10). Native Revit modelling was not run by these tests.

This release does not establish a fix for the reported Revit 2027 crash after B5
grading/3D navigation; the supplied crash dump contains no usable stack.
