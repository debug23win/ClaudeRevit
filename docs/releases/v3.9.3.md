# v3.9.3 — ModPlus headless adapters

Integrated the supplied headless adapter package into ClaudeRevit for Revit 2027:
85 module aliases plus `run_modplus_headless`, with 32 independent Revit API
operations across 27 modules. Agents can inspect native schemas, validate original
method bindings and execute typed pipelines without posting GUI commands.

- Native operations need no installed ModPlus DLL; original pipelines require
  loaded assemblies matching the binding snapshot's MVID and SHA-256.
- The code-execution switch remains enforced, together with tool-group settings
  and the bound active project. Dynamic tools forward preflight and transaction flags.
- Preview defaults to rollback. Adapters own their transactions, check cancellation
  before commit and produce one Undo group per committed call. Large results retain
  success/error and rollback fields within the transport budget.
- 378 registered tools in Revit 2027; 292 in Revit 2025/2026. English and Russian
  README files and the integration guide are updated.

Validation: 354 unit tests, 51 isolated adapter/policy checks and 42 managed headless
metadata/call-graph checks. CI and release packaging check the production assembly;
release packages undergo the existing mandatory Defender scans.

This is not a complete port of every ModPlus workflow or an arbitrary-code sandbox.
Live-model execution with Revit/ModPlus is still unverified. Previously postponed
review work remains outside this release.

[Coverage, examples and limits](https://github.com/debug23win/ClaudeRevit/blob/main/docs/modplus-headless.md).
