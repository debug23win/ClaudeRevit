Fixes Revit detection in the installer when Revit is installed on a custom drive.

The previous installer checked standard Program Files and ProgramData folders. A real Revit 2027 installation at `D:\Program Files\Autodesk\Revit 2027` was incorrectly marked “not detected”. The installer now reads both registry views, including localized Autodesk installation keys, and verifies the existing Revit.exe's year. Empty add-in folders and stale registry entries no longer count as installed Revit. Manual version selection remains available, and the plugin is still installed in the matching per-user Addins folder.

The version selection description now sizes itself to its wrapped text and display scale, preventing the clipped text shown in the reported screenshot.

Validation: compiled Inno detection checks passed for custom paths, localized keys, both registry views, wrong-year executables and stale registrations. The check also detected the actual Revit 2027 installation on D:. Regression checks now run in CI and before release packaging.

Correction to the v3.7 validation notes: Revit 2027 is installed on the local machine; the earlier inventory missed its custom path. This discovery does not establish that the new geometry tools have been exercised in live Revit.

All v3.7 BIM tools are included. Download the updated installer or the ZIP matching Revit 2025, 2026 or 2027.
