Original build notes (historical; the reset claim below is superseded):

Benchmark scores, complex family/rebar tasks, GPT-6.1 Sol discovery and installer fixes.

- **29 benchmark tasks**: ten new complex cases covering nested family associations,
  recursive shared/host analysis, independent size matrices, void cuts, revolve/sweep/
  blend/swept blend, a 120-column frame, multi-zone cages, slab openings, curved rebar
  and rebar schedule quantities. Family tasks run in an already open ordinary RFA;
  incompatible documents/missing seeds are skipped without points.
- **Quality, speed and total points**: independent evidence-based quality (0–100),
  fixed per-task speed references and `total = quality × (0.8 + 0.2 × speed / 100)`.
  Skipped/ungraded tasks are excluded from displayed averages. Formula version,
  references, budgets, judge choices and detailed metrics are stored in JSONL.
- **Benchmark crash fixed**: every all-element collector now has the required native
  filter for both instances and types. Reset now rolls back all per-task model changes
  using a native transaction group, including family parameters and existing element
  edits/deletions. Exported files are retained. The isolated native connectivity check
  includes instance/type collection and nested transaction-group rollback.
- **Objective evidence expanded**: host links, native rebar centerlines/layouts,
  coordinates, openings, schedule fields/rows, sheets and annotation owners. Added/
  changed/deleted element snapshots are retained before bounded judge sampling.
  Family flex checks run independently of the modeller's reported success.
- **Curved native beams**: `create_beam` accepts one line/three-point arc in millimetres
  while preserving the existing endpoint-in-feet interface.
- **GPT-6.1 Sol discovery fixed**: automatic CLI resolution chooses the highest actual
  installed Codex version instead of the first PATH entry. On the reported machine,
  PATH CLI 0.154.0 omitted the model; automatic selection of 0.159.2 returns eight
  models with `gpt-6.1-sol` as default. An explicit Settings path remains pinned;
  clear an old pinned path before refreshing. Models still come from the account catalog.
- **Installer detection fixed**: registered paths in both registry views and localized
  Autodesk keys detect custom-drive installs, including the actual Revit 2027 on D:.
  Executable year validation rejects stale registrations; wrapped version-selection
  text adapts to display scaling.

Validation: 152 pure tests, isolated real-WPF benchmark/pane checks, local HTTP/stdio
MCP checks, fake subscription CLI processes (including older/newer executable selection),
native compiled Inno detection fixtures, and builds for Revit 2025/2026/2027.
The real subscribed Codex catalog confirmed GPT-6.1 Sol without an inference turn.
Complex native geometry tasks and benchmark group rollback require execution
validation inside Revit; compilation and isolated runner tests do not prove live results.

All v3.7 BIM tools and standards are included. Both READMEs are updated.

contains task fixtures, scoring references and limits. Install the updated setup
or the ZIP matching Revit 2025, 2026 or 2027, then restart Revit.
