ClaudeRevit v3.7 expands the agent to **213 tools** and makes subscription benchmarking the default.

- Native family authoring: extrusion, blend, sweep, swept blend, revolution, solids/voids, labelled rectangular dimensions, nested family placement and parameter associations. Inspect nesting/formulas and flex types, sizes and variants with rollback.
- Native reinforcement: ordered line/arc geometry, shape-driven layouts, explicit free-form bars, constraint inspection/selection, couplers and schedule images. Complex geometry uses real Revit elements; it is not an automatic engineering design or fabrication check.
- Dimensions from stable references, cascade-checked deletion, material quantities, native beam systems and parameter colouring with legend data.
- BIMStarter command catalogue covers 63 source commands with explicit native/partial/interactive coverage. Installed ribbon commands can be posted, with completion verified separately. Source code and plugin binaries are not redistributed.
- ADSK 2019/2021 and BIMStarter references: 1,120 definition rows, 566 unique GUIDs, source types/flags and recommended ADSK parameter groups. Added source-based workflow guidance and a partial, opt-in Samolet EIR v5.0 audit.
- Benchmark defaults to the Codex subscription, supports independent modeller/judge models and effort, Claude Code subscription and explicit API mode. Added authentication/error checks, cancellation and cascade-safe cleanup of newly created elements.

Validation: 138 unit tests plus WPF interface, MCP transport and isolated CLI process checks. Real Codex subscription completions succeeded with two models.
