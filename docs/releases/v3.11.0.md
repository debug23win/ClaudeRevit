# v3.11.0 — Current Claude models from the Models API, benchmark log buttons, chat per drawing keeps your choices

## Claude models are read from Anthropic, like the Codex catalog

- The API and Claude Code model lists come from Anthropic's Models API (`GET /v1/models`) for your API key. Listing models runs no inference. Results are cached for 5 minutes; **Refresh models** re-reads them and now works for Claude agents as well as Codex.
- Without an API key (Claude Code on a subscription) or when the request fails, the current generation is shown: Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5. Sonnet 5 and Opus 4.8 are no longer the defaults.
- Claude Code receives the full model id (`claude-opus-5-5`) rather than a family alias, so the chosen model is the one that runs.
- The benchmark window uses the same catalog for Claude Code and API runs.
- Auto mode now runs Sonnet 5.5 with an Opus 5.5 advisor (Sonnet 5.5 rejects Opus 4.8 as advisor). Settings offer Sonnet 5.5 / Haiku 5.5 executors and Opus 5.5 / Fable 5.2 advisors; earlier saved choices move to the current model of the same tier.
- Pricing, thinking and history rules are keyed by model family and version, so any model the API returns is handled; Fable 5.2 pricing ($8 / $40 per million tokens) added.

## Benchmark window

- **Open log** opens the JSONL log of the current or latest run, also while it runs (falls back to Notepad when `.jsonl` has no associated program). **Log folder** opens `%APPDATA%\ClaudeRevit\benchmarks` with the latest log selected.

## Chat per drawing

- Chats stay separate per drawing and the pane still follows the active tab. A drawing opened for the first time now keeps the current agent, model and effort instead of resetting to Auto, and an unsent draft moves with you. Attachments stay with their drawing.

## Validation

- Unit and pane tests were updated for the catalog, model id parsing, pricing and the new pane lists. The changes were not compiled in the authoring environment (no .NET SDK available there); CI and the release workflow build and run the tests on Windows before publishing.
- Interactive acceptance inside live Revit remains unverified.
