# v3.8.4 — development notes, release pending

Adds objective benchmark checks and repeat/calibration statistics, wider geometry-driving
section generators, dependent node updates and actual bore inspection, multicategory
live SPDS schedules with explicit nesting policies, verified optional experience and
bounded resumable native-tool jobs. Six new tools bring the source catalog to 238.

- Benchmark quality is capped by mandatory independent evidence. Missing evidence
  cannot pass; fully missing evidence is ungraded. Calibration requires five successful,
  high-quality repeats in the same seed/environment/configuration.
- Native channel/angle/tube/paired-timber sections, explicit material/density and template
  placement driver; independent bounds/origin/volume flex checks reject broken constraints.
- Declared node dimension/placement dependencies refresh within Revit transactions;
  missing or manually edited parts require deliberate refresh. Actual inner cylindrical
  faces are checked for coaxial, through-solid bores; unsupported geometry stays incomplete.
- Live multicategory steel/timber source mappings, three-level nesting policies,
  material-volume/density mass and linked native schedule fields. Sheet audit checks
  field identity, totals, margins and overlaps; export inspection remains necessary.
- `verify_model_result`, `get_verified_experience`, `run_checkpoint_job`,
  `get_checkpoint_job`, `inspect_family_files`, `audit_spds_schedule`.
  Experience never mandates reuse. Saved RVT checkpoints prevent duplicate completed
  steps; unsaved edits are subject to ordinary Revit recovery.
- Release publication now requires an active, current Defender scan of staged payloads,
  final archives and the exact installer. Detection/errors block publication.
- Old reference RFA upgrade warnings are captured for newly opened background
  family documents and returned in inspection/flex reports. Upgrade errors roll
  back instead of being resolved by deleting geometry. User-opened documents are
  excluded from this handler.
- A [developer native acceptance harness](../../ClaudeRevit.NativeTests/README.md)
  creates analytical section/nested-family fixtures and disposable project cases
  for checkpoints, objective probes, dependent nodes and material-driven schedules.
  Compilation is automated; executed reports are still required for acceptance.

Pure logic, isolated UI/CLI/MCP and API compilation are automated; native family
constraints, updater execution and schedule rendering still require actual Revit
acceptance. The unchanged v3.8.3 installer passed a new scan after an official
Defender intelligence update; see
[security investigation](../installer-security.md). No new installer is published yet.
