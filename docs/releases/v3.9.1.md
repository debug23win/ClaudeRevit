# v3.9.1 — undo a whole action, safe bulk writes, DWG/IFC import, model versions, more norm rules

288 tools, up from 281. Details and limits: [guide](../norms-documentation-coordination.md).

## Agent safety

- **`undo_last`** rolls back the agent's whole last action in one call: every change made while answering the last request, or the last `steps` calls.
  - It uses Revit's own Undo, one verified step at a time.
  - If a manual edit of yours sits on top of the undo stack, it is restored with Redo and nothing more is undone.
  - `list=true` shows recent actions.
- **`plan_token`.** Every preview now returns a `plan_token` with the change counts.
  - Applying with the token runs only if the inputs and the model are unchanged since the preview.
  - The result then compares planned and actual changes.
  - Calls without a token behave exactly as before.
- **`survey_change_impact`** shows what an edit would also touch:
  - hosted inserts and rebar;
  - tags and dimensions;
  - joins;
  - groups;
  - pinned elements;
  - elements borrowed by others;
  - type instances.

## Imports and versions

- **`dwg_to_model`** turns a DWG underlay into grids, columns (rectangles and circles) and beams (parallel line pairs), working by layer.
  - Grids are named in the Russian convention: numbers left to right, letters bottom to top.
  - Sized types are matched, or created if you ask.
- **`ifc_to_native`** rebuilds DirectShapes from an opened IFC or an IFC link (Renga, Tekla, nanoCAD BIM) as native walls, floors, columns and beams.
  - Each new element's volume is checked against the original.
  - Shapes that are not box-like are skipped and reported.
- **`snapshot_model`** and **`compare_model_versions`** show what was added, deleted, moved, retyped, and which parameters changed between issues.
- **`check_model_package`** checks open models, or a folder of RVT files, before issue:
  - warnings;
  - rooms;
  - links and imported CAD;
  - in-place families;
  - purgeable elements;
  - required fields;
  - shared location.

## Norm audit

- **New sections.** `sp59` (СП 59.13330.2020: doors 0.9 m, paths 1.8 m, universal toilet cabin 2.2 × 2.25 m) and `fire_distance` (СП 4.13130.2013 table 1, between this building and its linked buildings).
- **Office rule file.** Edit `%AppData%\ClaudeRevit\norm-rules.json` to override thresholds, switch rules off or add your own, with no rebuild. An example is in `docs/examples/norm-rules.json`. The base rules behave as in v3.9.0.

## Other

- **Smaller core tool set.** The `save_tool` template is now served by `get_tool_source name="template"`, and two rarely used tools left the core set.
- **Corrected wording.** Tool and system texts no longer claim that code execution is always available; it follows the switch in Settings.
