# v3.9.0 (draft, not released)

These notes cover everything merged after v3.8.7, which is also unpublished, so the next release ships both. There are 264 tools, up from 238. Details and limits are in [norms, documentation, coordination](../norms-documentation-coordination.md).

## Russian norm audit and documentation

- **`audit_norms`** checks the model against СП 1.13130.2020 and СП 54.13330.2022:
  - evacuation doors, corridors and stairs;
  - ceiling heights;
  - minimum room areas;
  - railing heights.

  Each finding names the clause and gives the measured value next to the required one. Thresholds follow the clause variants for the functional class, climate subregion and occupancy, and you can override them per project.
- **`annotate_norm_findings`** marks findings on a view with leader notes and revision clouds, and can also write them to a parameter.
- **New documentation tools:**
  - `compute_tep` (ТЭП);
  - `create_room_explication` (a live schedule);
  - `create_floor_explication` and `create_finish_schedule`;
  - `fill_title_block`;
  - `fit_schedule_to_sheet` (frame-aware, splits tall schedules);
  - `number_rooms`.

## Import, coordination, analysis

- **`pdf_to_model`** turns a vector PDF plan into grids and walls. You calibrate it by two points, by plot scale, or by the grid names already in the model.
- **`check_clashes`** finds clashes within the model or against a link. It reports the overlap volume and can build a 3D review view. `export_ifc` and `export_nwc` handle exchange.
- **Analytical model tools:**
  - `get_analytical_model`;
  - `create_analytical_model`;
  - `create_structural_loads`;
  - `create_boundary_conditions`.

## QA and modelling

- **`detect_off_axis` / `fix_off_axis`** find walls, grids, beams and lines that are a fraction of a degree off 90° or 45°, and rotate them true (preview first).
- **`find_tag_overlaps` / `resolve_tag_overlaps`** find tag collisions in a view and move the tags to free space.
- **`create_stair`, `create_railing`, `create_floor_opening`** model stairs, railings and floor openings.
- **`get_project_location`, `create_toposolid`** read the project's location and model terrain.

## Agent and API

- **Server-side refusal fallback.** For Fable 5, Fable 5.1 and Opus 5, a classifier-declined request is answered by Anthropic's recommended fallback model:
  - the `fallback` marker is kept in history;
  - the declined model's abandoned tool calls are never run;
  - the transcript says which model answered;
  - usage is billed at that model's rate.

  It is on by default and can be switched off in Settings.
- **Fable 5.1 conversations are append-only.** Local compaction and tool-result aging are off for this model, and the server's compaction keeps the context bounded instead, because editing the history can make the API reject later requests (a 400 error).
- **Size limits on tool results.**
  - Numbers in tool results are rounded to 7 significant digits.
  - Results over 40,000 characters are cut, and the full result stays retrievable with `get_full_result`.
  - The task journal records each result's size.
- **"Not found" errors suggest the closest name** for levels, types and worksets, and say when an element id is stale.
- **`eager_input_streaming` is on for the code tools.** `strict` tool schemas were considered and not adopted (see the guide).
- **Anthropic SDK upgraded to 12.53.**
- **New tool groups:** Documentation, Coordination and Structural analysis. Each has Russian and English keywords that load the group automatically.
