Fixes two regressions in document session tracking:

- Chat text could appear and immediately disappear in an unsaved project or family.
- Benchmark startup could fail with “Benchmark document changed before copying the seed” even though the active document had not changed.

Revit can return different managed wrappers of the same open native document.
Session keys now use native document equality, remain stable across repeated
Idling/ViewActivated events and saving, and retire when the document closes.
Distinct unsaved documents, scratch copies and reopened files remain separate.
Benchmark cleanup and family reload checks also use native document equality.

The WPF regression probe compiles the production document-session code and chat
pane against isolated Revit wrappers. It verifies draft preservation, saved
benchmark seed identity, active-copy recognition, no false cancellation of chat,
real-switch cancellation and separation despite identical paths/hashes.
These checks use simulated native wrappers; this patch has not been executed
inside a live Revit session.

Includes all v3.7.2 functionality: 29 benchmark tasks, quality/speed/total points,
subscription defaults, independent modeller/judge choices, GPT-6.1 Sol discovery,
advanced family/rebar tools and Revit 2025/2026/2027 installers.

Close Revit before installing. Save a local non-workshared scratch RVT/RFA before
running benchmark tasks with fresh-copy reset enabled.
