Complex benchmark tasks with quality/speed points, independent document copies,
GPT-6.1 Sol discovery and custom-drive Revit installer detection.

- **29 tasks**, including ten complex cases: four associated nested children,
  recursive nesting/shared/host analysis, independent family size/type tests,
  solid/void cuts, revolve/sweep/blend/swept blend, a 120-column frame, zoned
  reinforcement, slab openings, curved native bars and checked rebar schedules.
- **Quality, speed and total** out of 100. The no-tools judge assesses actual
  Revit evidence; total is `quality × (0.8 + 0.2 × speed / 100)`. Speed uses fixed
  provisional task references. Ungraded/skipped tasks have no points and are
  excluded from means. Models/efforts, references, budgets and formula version
  are recorded in JSONL. Subscription is the default for modeller and judge.
- **Independent task copies**: save a local non-workshared scratch RVT/RFA with
  no pending edits. Each task opens a uniquely named temporary copy, collects
  evidence and closes it unsaved, restoring the seed. Cancellation closes only
  the owned copy. Project tasks require RVT; family tasks require ordinary RFA.
  F2/F3 need the nested fixtures described in the guide. External exports remain.
- **Revit callback boundaries corrected**: transactions/groups always end before
  an event handler returns. No group spans model inference or separate callbacks.
  The attempted v3.7.1 reset was withdrawn; its release is a draft, superseded by
  this version. Asynchronous API turns can have several undo entries.
- **Collector crash fixed**: the all-element census uses native instance/type
  filters. Evidence includes IDs/coordinates, host links, rebar centerlines/layouts,
  openings, schedule fields/rows, sheet viewports and annotation owners. Changed
  element evidence is retained before bounded sampling. Family flex runs independently.
- **Native curved beams**: `create_beam` accepts a line/three-point arc in mm,
  preserving legacy straight endpoint inputs in feet.
- **GPT-6.1 Sol discovery**: automatic selection chooses the highest actual
  installed Codex CLI version. On the reported machine, 0.159.2 exposes eight
  models with GPT-6.1 Sol as default; the old PATH CLI 0.154.0 omitted it. Explicit
  Settings paths remain pinned; clear an old path before refreshing models.
- **Installer**: localized registry keys, both registry views and EXE year
  validation detect custom-drive Revit, including the actual 2027 install on D:.
  Wrapped version-selection text adapts to display scaling.

Validation: 152 pure tests including the actual runner with isolated backends,
WPF pane/benchmark checks, HTTP/stdio MCP tests, fake CLI processes with version
selection, compiled native installer fixtures and builds for Revit 2025–2027.
The actual subscribed Codex catalog confirmed GPT-6.1 Sol without inference.
Complex geometry and scratch-copy activation/closing still require execution
validation inside Revit; compilation and isolated tests do not prove native success.
